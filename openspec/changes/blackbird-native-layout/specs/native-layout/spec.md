## ADDED Requirements

### Requirement: Выбор раскладки Blackbird Native
Настройки → Интерфейс SHALL предлагать четвёртую раскладку «Blackbird Native» рядом с «Сверху», «Сбоку» и Inbox, с собственным эскизом. Выбор MUST сохраняться так же, как другие раскладки. Раскладка по умолчанию MUST остаться прежней, а уже сохранённые значения других раскладок MUST читаться без изменений.

#### Scenario: Включение Native
- **WHEN** пользователь выбирает «Blackbird Native» в Настройках → Интерфейс
- **THEN** окно сразу перестраивается в раскладку Native, и после перезапуска приложения она остаётся выбранной

#### Scenario: Возврат к прежней раскладке
- **WHEN** пользователь в раскладке Native выбирает «Сбоку»
- **THEN** окно выглядит так же, как до появления Native, включая прежнюю настройку группировки боковой панели

### Requirement: Список сессий по проектам
В раскладке Native левая панель SHALL показывать вверху кнопку новой сессии и поиск, а под ними — сессии, сгруппированные по проектам, независимо от настройки группировки для раскладки «Сбоку». Каждую группу MUST быть можно свернуть, и у неё MUST быть действие «новая сессия в этом проекте».

#### Scenario: Сессии двух проектов
- **WHEN** открыты сессии в двух разных проектах и выбрана раскладка Native
- **THEN** левая панель показывает две группы с именами проектов, в каждой — сессии своего проекта

#### Scenario: Сессии внутри проектов
- **WHEN** выбрана раскладка Native
- **THEN** группы проектов по умолчанию раскрыты и показывают свои сессии, а отдельного списка открытых вкладок под проектами нет; свёрнутая пользователем группа остаётся свёрнутой

#### Scenario: Добавить проект
- **WHEN** пользователь нажимает «+» рядом с заголовком «Projects»
- **THEN** открывается выбор папки, и выбранные папки добавляются как проекты, как кнопкой «Добавить проект» на Главной

#### Scenario: Новая сессия в проекте
- **WHEN** пользователь нажимает «новая сессия» у группы проекта
- **THEN** открывается новая сессия в этом проекте

### Requirement: Настройки внизу левой панели
В раскладке Native внизу левой панели SHALL быть закреплена кнопка «Настройки», которая одним кликом открывает диалог настроек. Кнопка MUST оставаться видимой при прокрутке списка сессий.

#### Scenario: Быстрый вход в настройки
- **WHEN** пользователь нажимает «Настройки» внизу левой панели
- **THEN** открывается тот же диалог настроек, что и через «Главная → Настройки»

### Requirement: Полоса инструментов справа
В раскладке Native в правом верхнем углу окна сессии, над правой панелью, SHALL быть горизонтальный ряд иконок в порядке Claude Code: Сессия, Терминал, Изменения, Браузер, Файлы, затем меню «Вид» («…»). Клик по иконке MUST открывать правую панель на соответствующей вкладке (плагины `details`, `terminal`, `review`, `browser`, `file`), а клик по иконке уже активной вкладки MUST сворачивать правую панель. Активная иконка MUST визуально отличаться от остальных. Иконка инструмента, недоступного в этом окружении (например, браузера вне desktop), MUST NOT показываться. Шапка диалога и полоса вкладок правой панели MUST оставлять место под ряд, чтобы он ничего не перекрывал.

#### Scenario: Открытие изменений
- **WHEN** пользователь нажимает иконку «Изменения» при свёрнутой правой панели
- **THEN** правая панель открывается на вкладке изменений сессии, а иконка «Изменения» отмечена как активная

#### Scenario: Сворачивание повторным кликом
- **WHEN** правая панель открыта на вкладке «Терминал» и пользователь снова нажимает иконку «Терминал»
- **THEN** правая панель сворачивается, диалог сессии занимает освободившееся место

#### Scenario: Панель сессии
- **WHEN** пользователь нажимает первую иконку ряда («Сессия»)
- **THEN** правая панель открывается на вкладке деталей сессии во всю ширину панели

#### Scenario: Web без браузера
- **WHEN** приложение открыто в web-версии, где встроенного браузера нет
- **THEN** ряд показывает только Сессию, Терминал, Изменения и Файлы

### Requirement: Меню «Вид»
Последней кнопкой ряда («…») SHALL открываться меню «Вид» с переключателями: список сессий, правая панель и, когда в нижней панели есть вкладки, нижняя панель. Состояние переключателей MUST соответствовать тому, что сейчас видно на экране.

#### Scenario: Скрыть список сессий
- **WHEN** пользователь в меню «Вид» снимает отметку «Список сессий»
- **THEN** левая панель сворачивается, а повторная отметка возвращает её

### Requirement: Без заглушек неподдержанных возможностей
Раскладка Native MUST NOT показывать кнопки, вкладки или пункты меню для возможностей Claude Code, которых нет в blackbird. Такие возможности SHALL быть перечислены в таблице Todo в `design.md` этого изменения.

#### Scenario: Возможность из Todo
- **WHEN** у Claude Code есть элемент интерфейса, для которого в blackbird нет функциональности
- **THEN** в раскладке Native этого элемента нет, а в таблице Todo есть строка с ним
